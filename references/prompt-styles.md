# AI 生图提示词模板 (Prompt Styles)

为保证视频风格统一，请从以下风格库中选择一种贯穿全片：

## 🎬 风格库 (Style Library)

### 1. 电影级写实 (Cinematic Realistic)
适合：商业、传记、深度解析
> Prompt 后缀: `cinematic shot, hyper-realistic, 8k resolution, dramatic lighting, shot on 35mm lens, highly detailed --ar 16:9`

### 2. 3D 极简主义 (3D Minimalist)
适合：搞钱、工具书、干货
> Prompt 后缀: `3d render, minimalist, clean background, soft studio lighting, isometric view, pastel colors --ar 16:9`

### 3. 手绘插画风 (Hand-drawn Illustration)
适合：治愈系、个人成长、心理学
> Prompt 后缀: `digital painting, soft watercolor style, hand-drawn lines, dreamy atmosphere, warm color palette --ar 16:9`

### 4. 赛博朋克/科幻 (Cyberpunk / Sci-Fi)
适合：科技、未来趋势、AI 相关
> Prompt 后缀: `cyberpunk style, neon lights, futuristic city, dark background, glowing accents, cinematic composition --ar 16:9`

### 5. 杂志排版风 (Magazine Typography)
适合：封面、金句卡片
> Prompt 后缀: `magazine layout style, bold typography, high contrast black and white, modern design, clean composition --ar 16:9`

## 💡 提示词结构公式
`[主体描述] + [环境/背景] + [光影/氛围] + [风格后缀]`

**示例**：
"一个孤独的男人在深夜看着手机屏幕，房间全黑只有屏幕发着蓝光，压抑的氛围，cinematic shot..."
