# Video Compliance Rules — 短视频内容合规与敏感词库

## 适用平台
抖音 (Douyin)、TikTok、Bilibili、小红书、微信视频号

## 核心原则
1. **安全第一**：宁可不做，不碰红线。
2. **黑话替换**：平台算法对某些词汇有严格限制，需用圈内“黑话”替代。
3. **视觉合规**：画面中出现的内容（文字、Logo、人物）同样受审核。
4. **广告法**：严禁绝对化用语。

---

## 1. 极限词/广告法违规 🔴

**规则**：违反《广告法》，会被系统拦截或限流。

| 违规词 | 安全替换 | 示例 |
|--------|----------|------|
| 第一 / 唯一 / 绝对 / 最 | 领先 / 首选 / 核心 / 极佳 | "最好的方法" -> "极佳的方法" |
| 国家级 / 全球级 | 高标准 / 国际视野 | "国家级项目" -> "高标准项目" |
| 100% / 包过 / 保证 | 大概率 / 有助于 / 提升 | "包你学会" -> "助你快速掌握" |
| 赚大钱 / 暴富 / 躺赚 | 搞米 / 提升收入 / 副业 | "暴富指南" -> "搞米思路" |
| 治疗 / 治愈 / 根除 | 改善 / 缓解 / 调节 | "治愈焦虑" -> "缓解焦虑" |

## 2. 平台引流违规 🔴

**规则**：严禁在视频内容、标题、评论区直接引导私下交易或跨平台引流。

| 违规词 | 安全替换 | 场景 |
|--------|----------|------|
| 微信 / 加我 / 私信 | 粉丝群 / 后台 / 主页链接 | "加我微信" -> "看主页链接" |
| 下单 / 购买链接 | 橱窗 / 购物车 / 小黄车 | "点击购买" -> "看左下角" |
| 兼职 / 刷单 / 招聘 | 副业 / 搞米 / 合作伙伴 | "招兼职" -> "招募副业搭子" |
| 免费领 / 送钱 | 福利 / 惊喜 / 见面礼 | "免费送" -> "给粉丝准备了福利" |

## 3. 敏感话题/黑话替换 🟠

**规则**：部分词汇会被算法判定为“低质”或“敏感”，导致流量降级。

| 原始词 | 平台黑话 | 备注 |
|--------|----------|------|
| 赚钱 / 搞钱 | 搞米 / 面包 / 薯条 | 抖音/小红书常用 |
| 杀 / 死 | 没 / 挂 / 领盒饭 | 游戏/故事类常用 |
| 钱 / 人民币 | W (万) / 米 / 软妹币 | 避免谈具体金额 |
| 医院 / 医生 | 白大褂 / 那个地方 | 医疗健康类严控 |
| 宗教 / 迷信 | 传统文化 / 心灵力量 | 避免封建迷信判定 |
| 政治 / 国家大事 | 宏观 / 国际局势 | 避免时政敏感度 |

## 4. 视觉画面合规 (Visual Compliance) 🟠

**规则**：AI 生成的图片和视频必须经过审核。

- **禁止**：血腥、暴力、恐怖、色情、低俗擦边。
- **禁止**：明显的商标 Logo（如 Nike 勾、Apple 标），除非是评论该品牌。
- **禁止**：人民币/外币现钞特写（可用虚拟金币、数字代替）。
- **禁止**：二维码、微信号水印直接出现在视频画面中（容易被判营销号）。
- **注意**：AI 生图可能产生奇怪的肢体（多手指、扭曲），需修复否则会被判“引人不适”。

## 5. 版权风险 (Copyright) 🟡

- **BGM**：必须使用版权库音乐（剪映自带、抖音曲库、Epidemic Sound）。
- **字体**：使用免费商用字体（思源黑体、思源宋体、站酷系列），**严禁**使用微软雅黑（方正版权）。
- **素材**：AI 生图通常无版权争议，但不要直接使用他人的知名 IP 形象（如米老鼠、漫威角色）。

## 6. 自动改写策略 (Auto-Rewrite Logic)

当 AI 生成的文案命中上述违规词时，执行以下策略：

1. **同义替换**：用“安全替换”列的词汇直接替换。
2. **模糊化处理**：用“很多人”、“某大 V"、“圈内”代替具体人名或品牌。
3. **场景化描述**：用画面展示代替文字直述（如用金币堆叠代替“赚了 100 万”）。
4. **添加免责声明**：在视频结尾或简介添加“个人观点，不构成投资建议”等。

## 检查清单 (Pre-Upload Checklist)

在视频发布前，必须确认：
- [ ] 全文无极限词（最、第一、绝对）
- [ ] 无直接引流词（微信、加我）
- [ ] 无平台敏感词（杀、死、钱 -> 已替换）
- [ ] 封面文字不超过 5 个字且无违规
- [ ] 字体已确认为免费商用
- [ ] BGM 已确认版权来源
