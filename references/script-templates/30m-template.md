# 20-30 分钟沉浸精读脚本模板 (YouTube/播客)

## 核心结构 (Total ~3000-4500 字)

| 时间段 | 模块 | 目的 |
|--------|------|------|
| 0:00-1:30 | **引子** | 讲一个与书相关的真实故事/历史事件，引人入胜 |
| 1:30-3:00 | **作者全貌** | 作者生平 + 写作背景 + 时代精神 |
| 3:00-8:00 | **脉络拆解 (上)** | 第一部分核心思想，深度解析 |
| 8:00-14:00 | **脉络拆解 (中)** | 第二部分核心思想，结合实际案例 |
| 14:00-20:00 | **脉络拆解 (下)** | 第三部分，争议点或高阶应用 |
| 20:00-24:00 | **延伸思考** | 结合现代社会/其他书籍的跨界对比 |
| 24:00-27:00 | **个人感悟** | 主播视角的深度读后感 |
| 27:00-End | **结尾** | 总结升华 + 互动提问 |

## 🎨 视觉策略 (电影感)
- **慢节奏**：单张图片停留 5-10 秒，配合 **Ken Burns (缓慢缩放/平移)** 效果。
- **色调**：全片保持统一的电影级色调（如青橙色调、黑白胶片、复古暖色）。
- **氛围图**：多用环境、光影、人物背影，少用直白的说明图。
- **BGM**：史诗感或深度氛围乐，音量极低，衬托人声。
