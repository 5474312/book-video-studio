# 10-15 分钟深度视频脚本模板 (YouTube)

## 核心结构 (Total ~1500-2000 字)

| 时间段 | 模块 | 目的 |
|--------|------|------|
| 0:00-0:45 | **Intro** | 抛出全书最大悬念/痛点，引出书名 |
| 0:45-2:00 | **背景** | 作者背景 + 为什么写这本书 + 历史背景 |
| 2:00-4:30 | **核心观点 1** | 最重要的概念，详细解释 + 案例 |
| 4:30-7:00 | **核心观点 2** | 颠覆认知的概念，对比传统认知 |
| 7:00-9:30 | **核心观点 3** | 实操性最强的方法 |
| 9:30-11:30 | **延伸/争议** | 书中争议点 + 读者评价 + 你的看法 |
| 11:30-13:00 | **总结** | 全书精华浓缩 + 适用人群 |
| 13:00-End | **Outro/CTA** | 引导订阅 + 下期预告 |

## 🎨 视觉策略
- 每 30 秒必须切换一次视觉锚点（生图 -> 思维导图 -> 文字高亮 -> 数据图表）。
- 关键概念使用 **动态文字浮现**。
- BGM 随情绪起伏变化（ Intro 悬疑 -> 观点 1 平稳 -> 观点 2 激昂 -> 结尾 治愈）。
